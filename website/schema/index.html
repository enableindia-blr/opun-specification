OPuN schema packs

JSON-LD contexts, vocabularies and attribute definitions for every OPuN domain. Every network payload references the Beckn core context and the OPuN context for its domain.

Using the contexts

Include both contexts in every payload, for example for the livelihood domain:

"@context": [
  "https://schema.nfh.global/core/v2.0/context.jsonld",
  "https://opun.network/schema/livelihood/v1/context.jsonld"
]

Load contexts through a cached or local document loader rather than fetching them on every message. v1 in the path is the major version: files at a v1 URL only change in backward-compatible ways.

The schemas are published from the OPuN specification repository under the Apache License 2.0. Example payloads for every API are in the repository.
